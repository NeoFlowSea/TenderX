# TenderX — MVP веб-приложения

Закрытые тендеры с AI-анализом для бизнеса Узбекистана (кейс №19). Первая вертикаль — упаковка и расходники HoReCa.
Главная мысль: **самая низкая цена товара ≠ самая выгодная закупка**. Монетизация — 1% с поставщика за подтверждённую сделку, для заказчика бесплатно.

Один полный сценарий без бэкенда и авторизации: заказчик публикует закупку → поставщики A/B/C подают закрытые ставки → приём ставок завершается → вскрытие и сравнение по полной стоимости → выбор поставщика → сделка и комиссия 1%.

## Запуск

Нужен Node.js 20+ и npm.

```bash
cd app
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты (Vitest)
npm run build      # сборка в app/dist
npm run preview    # просмотр собранной версии
```

Сборка использует `base: './'` и hash-роутер, поэтому `dist/` работает с любого статического хостинга (в т.ч. GitHub Pages по адресу `/TenderX/`).

## Экраны и прямые ссылки

| Экран | URL |
|---|---|
| Список тендеров | `#/` |
| Новая закупка (заказчик) | `#/new` |
| Карточка тендера | `#/tender/t001` |
| Закрытая ставка (поставщик) | `#/tender/t002/bid?as=B` |
| Вскрытие и сравнение (заказчик) | `#/tender/t001/compare` |
| Сделка | `#/tender/t001/deal` |

Демо-ссылки для презентации и скриншотов:

- `#/tender/t002/bid?as=B&kp=example` — открыть форму ставки поставщика B, вставить пример КП и сразу разобрать его;
- `#/tender/t001/deal?choose=B` — сразу подтвердить выбор поставщика B в тендере #001 и показать сделку.

В шапке есть переключатель роли **Заказчик / Поставщик** (в роли поставщика выбирается демо-поставщик A, B или C), кнопка настроек AI и **«Сбросить демо-данные»**.

## Демо-данные

Данные хранятся в `localStorage` браузера, при первом заходе загружаются из `src/data/seed.json`. Время дедлайнов считается от момента первой загрузки.

- **Тендер #001 «Бумажные стаканы 250 мл»**, 50 000 шт., сеть кофеен, Ташкент, поставка до 7 дней. Уже вскрыт, цифры совпадают со слайдом «Демо»:
  - A — 11 000 000 + 300 000 = **11 300 000 сум**
  - B — 10 200 000 + 200 000 = **10 400 000 сум** — рекомендация
  - C — 9 700 000 + 1 100 000 = **10 800 000 сум** (самый дешёвый товар, но доставка съедает выгоду)
  - экономия против самого дорогого (A): **900 000 сум ≈ 8,0%**; комиссия 1% с B — **104 000 сум**.
- **#002 «Крышки для стаканов 80 мм»** и **#003 «Салфетки бумажные»** — открыты, есть закрытые ставки (видно количество, цены скрыты).

`src/data/market_prices.json` — **иллюстративные демо-данные** для рыночного коридора цены (у каждой строки поле `source`). Это не статистика stat.uz/UZEX; в интерфейсе коридор всегда подписан как демо-ориентир.

## Что считает код, а что AI

| Что | Как |
|---|---|
| Полная стоимость, фильтр по обязательным требованиям и сроку, рейтинг, экономия, рыночный коридор, комиссия 1% | Детерминированный TypeScript в `src/lib/analysis.ts`, покрыт тестами. AI здесь не участвует. |
| Разбор КП (свободный текст → поля ставки) | Без ключа — **офлайн-разбор по правилам** (`src/lib/parseOffer.ts`). С ключом — **Claude** извлекает поля, а арифметику (цена × количество, итого − доставка) всё равно делает код (`completeOffer`). Если Claude недоступен, используются правила, и интерфейс говорит об этом. |
| Объяснение «Почему?» | Без ключа — текст по правилам (`src/lib/explain.ts`) только из данных приложения. С ключом — кнопка «Объяснить с Claude»: модель получает уже посчитанные цифры и только формулирует текст. Ответ проверяется: если в нём есть число, которого нет в данных тендера, показывается предупреждение (`findUnknownNumbers`). |

Источник результата всегда подписан: **«⚙ офлайн-разбор (правила)»** или **«✦ AI (Claude)»**.

### Как включить Claude

1. Нажмите в шапке «AI: офлайн (правила)» и вставьте свой ключ Anthropic API.
2. Ключ хранится **только в localStorage этого браузера** и не попадает в код, сборку или репозиторий. Запрос идёт напрямую из браузера в `api.anthropic.com` через официальный SDK `@anthropic-ai/sdk` с `dangerouslyAllowBrowser: true` (SDK добавляет заголовок `anthropic-dangerous-direct-browser-access: true`).
3. Модель: `claude-opus-5-5`, structured outputs (`output_config.format` с JSON-схемой), `effort: low`, серверный fallback при отказе (`fallbacks: "default"`).

Ключ в браузере виден любому, у кого есть доступ к этому компьютеру, — для демо это допустимо, для продакшена вызовы нужно перенести на бэкенд. `.env` не используется.

## Ограничения MVP

- Нет бэкенда и авторизации: все роли переключаются в одном браузере, данные живут в localStorage.
- Разбор КП работает с текстом (сообщение, письмо, текст из PDF); загрузка файлов PDF/фото не реализована.
- Офлайн-парсер рассчитан на типичные формулировки («по 204 сум», «доставка 200 тыс», «5 дней», «за партию 9,7 млн»); необычный текст может разобраться не полностью — поля всегда можно поправить вручную.
- Рыночные коридоры — демонстрационные, не реальные рыночные данные.
- Одна категория (упаковка и расходники HoReCa), одна валюта (сум).
